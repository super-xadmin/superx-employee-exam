# แนวทางหน้าตา SuperX Academy

ปรับตาม Company Profile ที่ผู้ใช้ให้มา (`SuperX_AI_Company_Profile_TH.pdf`) และแนวทาง UI เรียบ โปร่ง อ่านง่ายตามที่ผู้ใช้ต้องการ

## เอกลักษณ์บริษัท

- ใช้โลโก้ SuperX ที่แยกจาก artwork ใน PDF หน้า 2 โดยรักษาสัดส่วนและความโปร่งใส
- ใช้ภาพฝูง RoboVan จาก artwork หน้าปก เป็นภาพประกอบหน้าเข้าสู่ระบบ
- โทนสีขาวและไซแอน พร้อมข้อความ Smart Mobility / Smart Communications จากทิศทางแบรนด์ในเอกสาร
- ไม่คัดลอกเนื้อหาข้อมูลเชิงธุรกิจหรือสถิติใน Company Profile มาเป็นเกณฑ์ข้อสอบ

## การออกแบบ UI

พื้นหลังขาวเทาอ่อน การ์ดมุมมน เงาบาง ช่องว่างรอบเนื้อหา และหัวข้อที่จัดลำดับชัดเจน เมนูด้านข้างเป็นสีอ่อน ส่วนแถบด้านบนโปร่งพร้อม blur ในเบราว์เซอร์ที่รองรับ ใช้ไอคอนเส้น SVG และแบบอักษรระบบของอุปกรณ์ ไม่แนบไฟล์ฟอนต์เฉพาะของ Apple

ปุ่มหลักใช้ไซแอนเข้มเพื่อให้ตัวอักษรขาวอ่านชัด แยกสีผ่าน/ไม่ผ่าน/รอประเมินตามสถานะ ข้อสอบใช้พื้นผิวเรียบ ไม่ใส่ภาพตกแต่งในเนื้อหาคำถาม มี focus ring และรองรับการลดการเคลื่อนไหวตามการตั้งค่าอุปกรณ์

## ไฟล์ที่แก้ไขหน้าตา

- `public/style.css` — รูปแบบร่วม หน้าล็อกอิน เมนู การ์ด ตาราง หน้าสอบ และ responsive
- `public/app.js` — โครงหน้าเข้าสู่ระบบ โลโก้ ไอคอน และข้อความหน้าแนะนำ
- `public/assets/superx-logo.png` — โลโก้จากไฟล์อ้างอิง
- `public/assets/robovan-fleet.webp` — ภาพ RoboVan ที่ปรับรูปแบบไฟล์เพื่อใช้บนเว็บ

ระบบยังใช้ Email OTP / Lark เท่านั้น ผู้ประเมินหลัก `phop@super-x.tech` เกณฑ์ผ่าน 95% และสอบซ่อมได้ 1 ครั้งตามเดิม

ทดสอบโค้ดและ API ผ่าน 51 กรณี และตรวจ CSS ด้วย esbuild สำหรับ Safari 16 / Chrome 110 แล้ว ยังไม่ยืนยันภาพหน้าจอจริง เนื่องจากสิทธิ์เข้าถึงหน้าเว็บผ่านเครื่องมือเบราว์เซอร์ถูกปิดอยู่
